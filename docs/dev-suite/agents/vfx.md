# VFX

## Summary
Visual and audio tuning beyond the Workshop's juice sliders: motif, pulse,
floats, beat timing, ceremony, wake flash, sky twinkle, palettes,
constellation point/edge geometry, and sound gains per cue.

## Visual
A "test sounds" button that plays each cue in sequence, then a flat knob
list (same row style as Balance/Names) walking every `VFX_DEFAULTS` key.

## Files
js/dev/panel.js (tabVfx), js/config/vfx.js, js/ui/sound.js

## Capabilities
Find or tune any visual/audio knob live, including sound gains (`sound.tap`,
`sound.fill`, etc.); edits persist as an override. New sound cues, new
palette acts, or new visual systems go to the prompt package.

## Hotkeys
None specific to this tab.
